# web-tools

簡易的なWebアプリを複数配置し、GitHub Pagesでまとめて公開するためのリポジトリです。

公開URL: https://toshi0907.github.io/web-tools/

## 構成

```
.
├── index.html          # 各アプリへのリンク一覧（トップページ）
├── apps.json           # index.html が読み込むアプリ一覧データ
├── assets/
│   └── style.css        # 共通スタイル
├── apps/
│   ├── _template/               # 新しいアプリを作る際のひな形
│   ├── favicon-generator/         # favicon作成ツール
│   ├── animal-shogi/               # どうぶつしょうぎ
│   ├── whiteboard-memo/             # 手書きホワイトボード＆メモ
│   ├── advanced-calculator/          # 高機能電卓
│   ├── photo-memo/                    # 写真メモアプリ
│   ├── pdf-split/                      # PDF分割ツール
│   ├── image-resize-zip/                # 画像一括リサイズ
│   ├── photo-to-pdf/                     # 写真PDF化ツール
│   ├── regex-replacer/                    # 正規表現置換ツール
│   └── home-dashboard/                     # ホームダッシュボード
└── .github/workflows/deploy-pages.yml  # GitHub Pagesへの自動デプロイ
```

## アプリ一覧

### favicon作成ツール (`apps/favicon-generator/`)

文字を入力してシンプルなfaviconを作成し、PNGおよびICO形式でダウンロードできるツールです。

- **入力項目**
  - 文字（最大4文字。空の場合は「W」を表示）
  - 背景色（カラーピッカー）
  - 文字色（カラーピッカー）
  - 形（四角 / 角丸四角 / 円）
  - フォント（ゴシック体 / 明朝体 / 等幅）
- **プレビュー**
  - 入力内容に応じてリアルタイムにcanvasへ描画
  - 実際のブラウザタブでの見え方を確認できるよう、このページ自体のfaviconも同時に更新
- **ダウンロード（PNG）**
  - 16x16 / 32x32 / 48x48 / 64x64 / 128x128 / 180x180（Apple touch icon向け） / 512x512 の各サイズをPNG形式で個別にダウンロード可能
  - 文字が背景の80%幅に収まるようフォントサイズを自動調整
- **ダウンロード（ICO）**
  - 16x16 / 32x32 / 48x48 / 256x256 を内包したマルチ解像度の `favicon.ico` をダウンロード可能
  - C#のWinFormsアプリなど、`Form.Icon`やプロジェクトのアプリケーションアイコンとして `.ico` が必要な場面向け
- **その他**
  - 外部ライブラリを使用せず、Canvas APIとICOファイルフォーマットの自前実装のみで完結（オフラインでも動作）

### どうぶつしょうぎ (`apps/animal-shogi/`)

3×4マスのミニ将棋「どうぶつしょうぎ」で遊べるアプリです。

- コンピューター対戦（ミニマックス法＋アルファベータ枝刈りのAI）と、ふたりで交代しながら遊ぶモードを切り替え可能
- ライオン・ゾウ・キリン・ヒヨコ（🐔ニワトリに成る）の駒を絵文字で表示し、あそびかたのルールも画面内に表示
- 相手の駒を取ると持ち駒になり、盤上に打てる（打ち歩詰め相当の反則マスは自動で制限）
- ライオンを捕まえる、または相手陣まで安全に進む（トライ）ことで勝敗が決まる

### 手書きホワイトボード＆メモ (`apps/whiteboard-memo/`)

マウス・タッチ・ペン入力に対応した手書きホワイトボードアプリです。

- ペンの色・太さを自由に変更でき、消しゴムツールと元に戻す（undo）に対応
- 書いた内容はメモとして保存でき、一覧からブラウザの`localStorage`に保存された過去のメモを呼び出せる

### 高機能電卓 (`apps/advanced-calculator/`)

括弧や演算子の優先順位に対応した関数電卓です。

- 進数変換（2進数／8進数／16進数）と、度・ラジアンの角度変換に対応
- Deg/Radの角度モード切り替え、計算履歴の表示・消去、キーボードからの入力にも対応
- `x=5` のように入力すると値を変数として保存でき、以降の式でその変数を使用可能。変数名入力欄と追加ボタンから初期値0の変数を直接追加することもできる。保存した変数は一覧表示され、名前クリックで式に挿入、値は一覧上で直接編集可能（編集するとメイン計算式の結果も再計算される）、個別削除・一括削除にも対応（`localStorage`に保存）
- 計算履歴は計算した時点の変数の値をスナップショットとして保持するため、後から変数の値を変更しても過去の履歴の結果は変わらない。履歴の各項目には、その計算で使われた変数とその時点の値も併記される
- 計算結果はJavaScriptが誤差なく扱える整数の範囲（2<sup>53</sup>-1）に収まらない場合、オーバーフローエラーとして表示

### 写真メモアプリ (`apps/photo-memo/`)

カメラで撮影した写真、または選んだ写真の上に手書きでメモを書き込めるアプリです。

- `getUserMedia`によるカメラ起動、またはファイル選択のどちらからでも写真を取り込み可能
- ペンの色・太さを指定して写真の上に書き込み、完成したメモはブラウザの`localStorage`に保存

### PDF分割ツール (`apps/pdf-split/`)

PDFをアップロードして、1ページずつ・指定したページ範囲・最大ページ数ごとのいずれかの方法で分割し、ZIPにまとめてダウンロードできるツールです。

- **分割方法**
  - 1ページずつ分割（全ページを1ページ1ファイルのPDFに）
  - ページ範囲を指定して分割（例: `1-3,4-10,11` のようにカンマ区切りで複数範囲を指定、範囲ごとに1ファイル）
  - 最大ページ数を指定して分割（先頭から指定ページ数以下になるよう連続したまとまりに分割）
- **出力**
  - 分割後のPDFはすべてZIPにまとめて一括ダウンロード
- **エラー処理**
  - PDF以外のファイル、破損したPDF、不正なページ範囲指定などはページ内にエラーメッセージを表示
- **その他**
  - PDFの解析・生成に `pdf-lib`、ZIP生成に `JSZip` をCDN経由（SRI付き）で読み込んで使用

### 画像一括リサイズ (`apps/image-resize-zip/`)

複数の画像をアップロードして、指定したピクセル数に一括リサイズし、ZIPにまとめてダウンロードできるツールです。

- **入力**
  - 「写真から選択」（`accept="image/*"` の入力。Androidではフォトピッカーが開く）と「ファイルから選択」（種別制限なしの入力。Androidでは通常のファイルチューザーが開き、Dropbox・pCloudなどSAF対応の他アプリも選択可能）の2つのボタンから画像ファイルを複数選択可能。選択するたびに一覧に追加され（置き換わらない）、両方のボタンを使い分けて何度でも画像を追加できる（選択した各画像のサムネイルと、ZIPに入る際の出力ファイル名、サイズを一覧表示。出力ファイル名にマウスオーバーすると元のファイル名を確認できる）
  - 一覧の各画像には個別削除ボタン（×）があり、選択を間違えた画像だけを取り除ける。「選択をすべてクリア」ボタンで一覧を空にできる
  - リサイズ後の幅・高さ（px）を数値で指定（初期値は1200×1200px）
  - 「縦横比を固定する」チェックボックス（オンの場合、指定した幅×高さの枠に収まるよう画像ごとの縦横比を保って拡大縮小。オフの場合は指定サイズぴったりに変形）
- **出力**
  - リサイズ後の画像は元のアップロードファイル名を使わず、EXIFの撮影日時（DateTimeOriginal）から生成したファイル名（例: `20260809_153000.jpg`）でZIPにまとめる。EXIFの撮影日時が取得できない画像は、ZIP作成時点の時刻に連番を付けたファイル名（例: `20260809_153000-1.jpg`）にする（JPEG/PNG/WebPは元の形式を維持し拡張子もそれに合わせる。それ以外の形式はPNGに変換し拡張子も`.png`にする。同名ファイルがある場合はさらに連番を付与）
  - ZIP作成後、自動ダウンロードはせず「ZIPをダウンロード」ボタンを押したタイミングでダウンロードする
  - ダウンロードするZIPファイル名は `resized_images_yyyymmdd-hhmm.zip`（ZIP作成時点の日時）
  - ZIP作成完了時にZIPファイルの容量（B/KB/MB）を表示
  - Web Share API（`navigator.share`）に対応した環境では「共有（メールで送るなど）」ボタンも表示され、OSの共有シートからメールアプリなどにZIPファイルを添付して送れる（非対応環境ではボタン自体を表示しない）
- **その他**
  - 画像のリサイズはCanvas APIで行い、ZIP生成に `JSZip` をCDN経由（SRI付き）で読み込んで使用
  - Android端末の「フォトピッカー」経由で選択した画像はブラウザが渡すファイル名が元のファイル名と異なる（内部IDベースの名前になる）ことがあるため、アップロード時のファイル名に依存しないEXIF撮影日時ベースの命名にしている

### 写真PDF化ツール (`apps/photo-to-pdf/`)

複数の写真をアップロードして1つのPDFにまとめ、ダウンロードできるツールです。

- **入力**
  - `accept="image/*"` の入力から画像ファイルを複数選択可能。選択するたびに一覧に追加され（置き換わらない）、何度でも写真を追加できる
  - 一覧の各写真にはサムネイル・ファイル名に加えて、「↑」「↓」（一覧内での並び替え。PDFのページ順に反映）、「↻」（90度ずつ回転。サムネイルにも回転を反映）、「×」（個別削除）の各ボタンを表示。「選択をすべてクリア」ボタンで一覧を空にできる
- **レイアウト**
  - 「1ページに1枚」（1枚を1ページいっぱいに配置）
  - 「1ページに2枚」（1ページを上下2段に分割して配置）
  - 「1ページに4枚」（1ページを2×2に分割して配置）
  - いずれのレイアウトも、各写真は縦横比を保ったまま各枠に収まる最大サイズで中央揃えに配置される
- **出力**
  - PDFはA4サイズ（縦向き固定）で生成され、`yyyymmdd-hhmm.pdf`（作成時点の日時）というファイル名で自動的にダウンロードされる
  - 各写真は回転を反映した上でJPEG化してPDFに埋め込むため、元の画像形式（JPEG/PNG/WebPなど）によらず出力できる
- **その他**
  - PDFの生成に `pdf-lib` をCDN経由（SRI付き）で読み込んで使用

### 正規表現置換ツール (`apps/regex-replacer/`)

検索パターンと置換文字列の正規表現セットを登録し、入力したテキストにリアルタイムで適用できるツールです。

- **正規表現クイックリファレンス**
  - ページ上部の折りたたみ領域に、検索パターン・置換文字列でよく使う記法（`.` `\d` `^` `$` `(...)` `$1` など）の早見表を表示
- **セットの登録・編集**
  - 「セットを追加」ボタンで空のセットを一覧に追加し、一覧内の各項目（セット名・検索パターン・置換文字列・フラグ g/i/m/s・1行ずつ処理）を直接インライン編集する方式（登録用の別フォームはなく、一覧がそのまま編集画面を兼ねる）
  - 入力するたびに正規表現として有効かどうかを検証し、不正な場合や検索パターンが未入力の場合はセットの項目内にメッセージを表示
  - 各セットは「↑」「↓」ボタンで並び替え可能、「削除」ボタン（確認あり）で個別削除可能
  - セットの内容・並び順・有効/無効の状態はブラウザの`localStorage`に保存される
- **テキスト変換**
  - 入力欄・出力欄は上下に配置（縦積み）で、どちらも高さをドラッグして変更可能
  - 入力欄にテキストを入力する、またはセットの内容を編集するたびに、チェックボックスで有効にしたセットを一覧の並び順に先頭から順番に連続適用（チェーン）し、出力欄にリアルタイムに反映
  - セットごとに「1行ずつ処理」を有効にすると、入力テキストを1行ずつに分けてそれぞれに検索・置換を適用（`^`や`$`を各行の先頭・末尾として使いたい場合や、複数行の間の行にも行頭の正規表現を適用したい場合に使用）
  - 置換文字列には `$1` などのキャプチャグループ参照も使用可能（JavaScriptの`String.replace()`の置換文字列構文に準拠）
  - 適用中の正規表現が不正な場合は、該当セット名とエラー内容を出力欄の下に表示し、そのセットの適用のみスキップ
- **出力のコピー**
  - 出力欄をクリックするとクリップボードに変換結果をコピーし、コピー完了を一時的に表示
- **エクスポート・インポート**
  - 「エクスポート」ボタンで登録済みの全セットをJSONファイルとしてダウンロード（ファイル名は `regex-sets_yyyymmdd-hhmm.json`）
  - 「インポート」ボタンでJSONファイルを選択して読み込み、既存セットへの「追加」または「置き換え」を確認ダイアログで選択可能

### ホームダッシュボード (`apps/home-dashboard/`)

ブックマークをカテゴリ分けして並べる、自分専用のスタートページです。

- **メモ**
  - ページ上部のテキストエリアにテキストを入力して「テキストメモを追加」ボタンで登録
  - テキストエリアにフォーカスした状態でクリップボードの画像をCtrl+Vで貼り付けると、その時点で画像メモとして自動的に登録（`data:` URLとして保存）
  - テキストメモ・画像メモは新しい順に一覧表示され、個別に削除可能
  - テキストメモは一覧の「編集」ボタンからテキストエリアに読み込んで内容を書き換え、「更新」ボタンで反映可能（「キャンセル」ボタンで編集を中断）。画像メモは編集不可（削除して貼り付け直す）
- **ブックマークとカテゴリ**
  - 「カテゴリとブックマークの管理」から、カテゴリ（名前・配置ペイン・表示時に折りたたむかどうか）とその中のブックマーク（タイトル・URL・favicon URLの任意指定）を一覧上でインライン編集する形で登録
  - URLは `http:`/`https:`/`file:`（ローカルファイル）以外（`javascript:` など）を弾き、不正な入力欄は赤枠で表示。無効なURLのブックマークは表示エリアに出さない
  - カテゴリ・ブックマークともに「↑」「↓」ボタンで並び替え、「削除」ボタン（確認あり）で個別削除可能。カテゴリを削除すると、含まれるブックマークもまとめて削除される
  - favicon URLを指定していないブックマークは、Googleの公開favicon取得サービス（`https://www.google.com/s2/favicons`）から自動取得。「表示設定」でドメイン（サブドメイン一致も可）を登録すると、そのドメインだけは外部サービスを使わず `https://<ドメイン>/favicon.ico` を直接参照する。また「表示設定」で「元ドメイン → 代替ドメイン」を登録すると、外部favicon取得サービスへの問い合わせ時にドメインを置き換える（例: サブドメイン単体ではfaviconを自動取得できないが親ドメインなら取得できる場合に、親ドメインを代替先として登録する）。favicon画像の読み込みに失敗した場合は絵文字アイコンで代替表示
- **表示エリア（ペイン）**
  - 「表示設定」でペイン数を1〜4から選択でき、各カテゴリは「配置ペイン」で指定したペインの、カテゴリ一覧内の並び順どおりに表示される
  - 各カテゴリは折りたたみ可能な`<details>`で表示され、初期状態（開く/閉じる）はカテゴリごとに設定可能
  - ブックマークはfaviconとタイトルのリンクとして表示され、クリックすると新しいタブで開く
- **データ**
  - ペイン数・カテゴリ・ブックマーク・メモ・favicon自動取得の除外ドメイン・favicon自動取得の代替ドメインは、すべてブラウザの`localStorage`に保存
  - 「エクスポート」ボタンで全データをJSONファイルとしてダウンロード（ファイル名は `home-dashboard_yyyymmdd-hhmm.json`）
  - 「インポート」ボタンでJSONファイルを選択して読み込み、既存データへの「追加」（IDを振り直して追加）または「置き換え」を確認ダイアログで選択可能

## 新しいアプリを追加する手順

1. `apps/_template/` を `apps/<新しいアプリ名>/` としてコピーする
2. `apps/<新しいアプリ名>/index.html` を編集してアプリを実装する
   （共通スタイルは `../../assets/style.css` を参照）
3. `apps.json` に以下の形式でエントリを追加する

   ```json
   {
     "name": "アプリの表示名",
     "path": "apps/<新しいアプリ名>/",
     "description": "アプリの簡単な説明"
   }
   ```

4. `manifest.json` の `name`/`short_name` と `icon.svg` 内の1文字を新しいアプリに合わせて書き換える
5. この README.md の「構成」のディレクトリツリーと「アプリ一覧」に、追加したアプリの説明を追記する
6. `main` ブランチにpushすると GitHub Actions が自動でGitHub Pagesにデプロイします。

既存アプリに機能を追加・修正した場合も、「アプリ一覧」内の該当する説明を実際の挙動に合わせて更新してください。

## Chromeへのインストールについて

各アプリはPWAとして、Chromeのアドレスバーからアプリ単体をインストールできます（トップページはインストール対象外）。各アプリディレクトリの `manifest.json` / `icon.svg` / `sw.js` がその設定です。オフラインキャッシュは行わず、インストールを可能にするための最小限の構成です。

## GitHub Pagesの設定

リポジトリの Settings > Pages で、Source を "GitHub Actions" に設定してください。
`.github/workflows/deploy-pages.yml` が `main` ブランチへのpushをトリガーに
自動でビルド・デプロイを行います。
