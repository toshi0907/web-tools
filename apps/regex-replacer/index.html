正規表現置換ツール

正規表現（検索パターン＋置換文字列）のセットを登録しておき、入力したテキストにリアルタイムで適用します。複数のセットを選んで順番に連続適用できます。

正規表現クイックリファレンス

検索パターンでよく使う記法

.改行以外の任意の1文字
\d / \D数字 / 数字以外
\w / \W英数字とアンダースコア / それ以外
\s / \S空白文字（スペース・タブ・改行など） / それ以外
^ / $行頭 / 行末（「1行ずつ処理」を使うと各行の先頭・末尾になる）
* / + / ?直前の要素が0回以上 / 1回以上 / 0か1回
{n} / {n,m}ちょうどn回 / n〜m回
[abc] / [^abc]a・b・cのいずれか / a・b・c以外
a|baまたはb
(...)グループ化（置換側で $1, $2 ... として参照可能）
(?:...)参照しないグループ化
(?=...) / (?!...)直後に...が続く / 続かない（先読み）
\. \( など記号そのものを検索したいときのエスケープ

置換文字列でよく使う記法

$1, $2 ...検索パターンの対応するグループにマッチした文字列
$&マッチした文字列全体
$$$ 自体
